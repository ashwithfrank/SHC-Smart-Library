# 📚 SHC Smart Library

A smart library management system designed to improve library operations and make accessing and managing library resources easier.

## 🌟 Overview

**SHC Smart Library** is a software project focused on modernizing library management at Sacred Heart College (SHC).

The project aims to provide a more convenient way to manage library resources and improve the experience for students and library administrators.

This repository contains the source code for the project.
